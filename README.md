# 第二世界摄影海报

把一张照片变成上下两个世界：上半保留原照，下半让照片中的核心主体成为可提起、展开、撑住或进入的立体摄影物体。

**关键区别：生成模型只负责下半幅，脚本直接用原图拼接上半幅。** 不靠模型遵守像素位置来保证 3:4 和上下各半。

## 使用

把此仓库完整放入 Codex 的 `~/.codex/skills/second-world-photo-poster`，保留 `scripts/`、`references/` 和 `agents/`。重新打开会话后调用：

```text
使用 $second-world-photo-poster，基于这张照片生成第二世界摄影海报。
```

需要支持参考图编辑的图像生成工具，以及 Python 3 + Pillow。Skill 自身不提供生图服务或 API key，不会自动购买服务。缺少 Pillow 时可在自行选择的虚拟环境安装 `requirements.txt`。

1. 观察原图并锁定主体，检查裁切能否保留完整主体。
2. 根据原照片生成独立的 3:2 下半幅，保留主体摄影质感，加入纸面、卷曲、厚度和投影。
3. 使用附带脚本拼接成 3:4 PNG。
4. 检查脚本记录，再人工复核主体身份、互动和画面质量。

```bash
python3 scripts/compose.py --photo original.jpg --lower lower.png --output output/poster.png
python3 scripts/test_compose.py
```

脚本默认输出 1500×2000；分界线为 y=1000。原照先按 EXIF 方向读取，然后等比裁切缩放，不做生成式重绘、调色或内容替换。建议使用 sRGB 输入。默认拒绝覆盖现有成品。下半幅非 3:2 时默认停止，只有确认安全裁切后才加 `--crop-lower`。

完整执行规则见 [SKILL.md](SKILL.md)，下半幅提示词见 [references/lower-panel-prompt.md](references/lower-panel-prompt.md)。

## 保证与边界

- 可验证：最终尺寸、严格上下各半、上半与原图裁切缩放结果一致。
- 需视觉判断：主体大部分轮廓完整、真实摄影质感、材料立体感、文字与小人互动。
- 不能保证：生成式下半幅逐像素复用原照片纹理。若需要这种保真程度，应采用真正抠图和变形的专门流程。
- 竖长主体可能无法完整放进铺满的 3:2 上半幅，需用户选择裁切或留边，不静默拉伸或补图。
- 当前仓库验证了结构合成与失败处理，尚未完成全新照片从下半幅生成到成品的端到端视觉验收。此前整图生成的概念稿未满足严格分区要求，不作为合格示例。

公开仓库不附带用户上传的原照片或其衍生图。未来添加真实示例前应取得对应图片公开展示授权。
